# The Workshop
The beginning. The cat is on his desk, along with the software box. The command "git init" turns the workspace into a local repository that tracks every change.

# The Backyard
"git add" places the box in the yard to get it ready. "git commit -m" affixes a label to it describing what has changed, so that it is preserved as a version.

# The Shipping Parking
There is the truck. If it has no destination, "git remote add origin" sets the GPS to the address of the repository on GitHub. "git remote -v" displays the destination for confirmation. "git push" loads the boxes into the truck, and it sets off.

# Main Warehouse
The truck arrives at GitHub, where the programs from all the cats who sent them are displayed for everyone to see. From there, others can take the latest version and propose modifications by submitting a pull request.
